# Week In Review

Uma revista semanal sobre inteligência, poder e valor humano,
por Hygor Beltrão Amorim.

Cinco conversas por semana, lidas juntas: cada uma vira um artigo de
cerca de cinco minutos, e a edição inteira vira um episódio em áudio.

**Leia em https://hygoramorim.github.io/week-in-review/**

Este repositório contém apenas o site publicado.
